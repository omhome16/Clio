# M8 — Agentic Ask panel + theme system

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent chat panel to the dashboard that answers questions about an analyzed repo by calling the existing sandboxed tools (files, graph queries, impact, archive), plus a light/dark theme system — all stdlib, reusing the existing `Subagent` loop and `ToolRegistry`.

**Architecture:** A new `clio/ask.py` module holds `AskSession` (per-job message history) and chat tools built as closures over the job id. Each `GET /api/ask?job_id=&q=` SSE turn runs the existing `Subagent.run` loop with a `ToolRegistry` seeded with `BUILTIN_TOOLS` + chat tools; `ask.tool` / `ask.final` events stream to the client. The dashboard gets per-job ask queues mirroring the existing `run_job` SSE pattern. Frontend: a collapsible right-side panel + CSS custom-property themes with a masthead toggle, `prefers-color-scheme` default, and localStorage persistence.

**Tech Stack:** Python 3.11 stdlib (`threading`, `asyncio`, `urllib`), existing modules only (`subagent`, `tools`, `events`, `reports`, `impact`, `store`). Zero new dependencies. Frontend: inline HTML/CSS/JS inside `web.py`'s `INDEX_HTML` (no CDN, no framework).

## What M8 delivers

1. **`clio/ask.py`** — `AskSession`: per-job persistent `history` of `LLMMessage`s; `run_turn(question, bus)` runs one `Subagent` turn (task text carries prior turns), appends to history, publishes `ask.tool`/`ask.final` events.
2. **Chat tools** — `read_file`, `grep`, `list_tree` (reused from `clio.tools`, sandbox-contained) plus `graph_query` (callers_of / callees_of / modules_importing / module_imports / has_symbol), `impact`, `list_jobs`, `get_report` (over `ReportArchive`).
3. **SSE endpoint** — `GET /api/ask?job_id=<id>&q=<text>`: one turn per request, streams `ask.tool` (name+args+ok+result), `ask.final` (answer+ok), then `event: done`. 400 when `q` missing, 404 for unknown jobs.
4. **Theme system** — CSS custom properties under `html[data-theme="light"|"dark"]`, toggle button in the masthead, default from `prefers-color-scheme`, persisted in `localStorage["clio-theme"]`. Dark palette = cyanotype inverted (warm ink paper, brightened Prussian blue; contrast re-checked >= 4.5:1, see design decisions).
5. **Ask panel UI** — collapsible right sidebar (bubbles for Q/A, inline tool-call lines, Enter to send, disabled while running, empty-state copy, error bubbles).

## Design decisions

- **Multi-turn context without touching `subagent.py`:** `AskSession._task_text` prepends the last 6 history messages as a `[Prior conversation]` transcript to the question; `Subagent` itself keeps its M1 contract unchanged. History is appended after every turn (user question + assistant answer).
- **Chat tools are closures over `job_id`; the archive root derives from the workspace** the registry passes in (`workspace.parent` — sandbox layout is `root/<job_id>` while the archive lives at `root/jobs/`). No new `ToolRegistry` contract changes; `path_arg` containment for `read_file` is inherited from the builtin tool.
- **`ask.tool` events come from an instrumented registry wrapper** (`_InstrumentedRegistry`) that wraps `ToolRegistry.execute` and publishes an `EVENT_ASK_TOOL` per call with `{tool, args, ok, result[:400], error}`; `EVENT_ASK_FINAL` is published by `run_turn` after the subagent completes. Event type constants `EVENT_ASK_TOOL`/`EVENT_ASK_FINAL` are added to `events.py` alongside the existing constants.
- **Ask runs like `run_job`:** `Dashboard.run_ask` is executed in a daemon thread via `asyncio.run(session.run_turn(...))`; events land in a per-job deque (`ask_start`/`ask_snapshot`/`_publish_ask` mirror `register_job`/`snapshot`/`_publish`), and the SSE handler drains it then writes `event: done`. The subscriber only forwards `ask.*` events (subagent internals stay out of the wire).
- **Unknown job = 404** when the job is neither in-flight (`Dashboard._jobs`) nor archived (`ReportArchive.get_report`); missing `q` = 400.
- **Client per session:** `Dashboard.ask_session` lazily builds `AskSession(job_id, root, make_client(get_provider(), get_limits()))` so the mock provider keeps the dashboard offline by default.
- **Theme tokens:** existing `:root` variables move into `html[data-theme="light"]`; dark overrides warm ink paper `#191512`, ink `#EFE9DC`, muted `#A89F8E`, rule `#3B362C`, brightened Prussian blue `#7FA5F5` (hover `#9DB9F7`), ok `#7FB98F`, bad `#E07B6F`. Contrast on `#191512`: muted ~6.7:1, blue ~7:1, ok ~8:1, bad ~4.7:1 — all >= 4.5:1.
- **Ask panel is a fixed right drawer** (`transform: translateX(102%)`, `.open` slides in) so the existing 2-column grid and tests stay untouched; `prefers-reduced-motion: reduce` disables the transition.
- **UI testability without a browser:** theme presence is asserted on the served HTML/JS source (`clio-theme`, `prefers-color-scheme`); chat behavior is covered end-to-end through the SSE endpoint with a scripted client.

## Contracts

- `clio.events.EVENT_ASK_TOOL = "ask.tool"`, `clio.events.EVENT_ASK_FINAL = "ask.final"`
- `clio.ask.ASK_SYSTEM_PROMPT` — system prompt for the ask subagent
- `clio.ask._make_chat_tools(job_id: str) -> tuple[Tool, ...]` — `graph_query`, `impact`, `list_jobs`, `get_report`; handlers `(args, workspace) -> str`
- `clio.ask.AskSession(job_id: str, root: Path | str, client: LLMClient, limits: Limits | None = None)` — `.history: list[LLMMessage]`; `async run_turn(question: str, bus: EventBus | None = None) -> dict{answer, ok, steps, tool_calls}`
- `clio.web.Dashboard.ask_session(job_id) -> AskSession` (lazy), `ask_start(job_id)`, `ask_snapshot(job_id) -> (list[dict], bool)`, `run_ask(job_id, question)`
- HTTP: `GET /api/ask?job_id=&q=` → 200 SSE (`text/event-stream`, `data:` lines, then `event: done`), 400 (missing q), 404 (unknown job)

```python
# src/clio/ask.py
"""Agentic Ask panel: per-job chat sessions that answer questions about an
analyzed repo by calling sandboxed tools (files, graph, impact, archive)."""
from __future__ import annotations

import json
from pathlib import Path

from clio.config import Limits, get_limits
from clio.events import EVENT_ASK_FINAL, EVENT_ASK_TOOL, Event, EventBus
from clio.impact import impact_of_symbol
from clio.llm import LLMClient, LLMMessage
from clio.reports import ReportArchive
from clio.sandbox import Sandbox
from clio.subagent import Subagent, SubagentSpec
from clio.tools import BUILTIN_TOOLS, Tool, ToolRegistry, ToolResult

ASK_SYSTEM_PROMPT = (
    "You are Clio's repository analyst. Answer the user's question about the "
    "analyzed repository using the available tools; cite module names and "
    "symbol ids when relevant. When you have the answer, reply with the JSON "
    '{"final": "your answer"}. Be concise.'
)


def _make_chat_tools(job_id: str) -> tuple[Tool, ...]:
    """Archive/graph tools bound to one job. The sandbox root is derived from
    the workspace the registry passes in (workspace.parent)."""

    def graph_query(args: dict, workspace: Path) -> str:
        store = ReportArchive(workspace.parent).graph_store(job_id)
        kind = args.get("kind", "")
        if kind == "callers_of":
            return json.dumps(store.callers_of(args["symbol_id"]))
        if kind == "callees_of":
            return json.dumps(store.callees_of(args["symbol_id"]))
        if kind == "modules_importing":
            return json.dumps(store.modules_importing(args["module"]))
        if kind == "module_imports":
            return json.dumps(store.module_imports(args["module"]))
        if kind == "has_symbol":
            return json.dumps(store.has_symbol(args["symbol_id"]))
        raise ValueError(f"unknown graph_query kind '{kind}'")

    def impact(args: dict, workspace: Path) -> str:
        report = impact_of_symbol(
            ReportArchive(workspace.parent), job_id, args["symbol_id"]
        )
        return json.dumps(report.to_dict())

    def list_jobs(args: dict, workspace: Path) -> str:
        jobs = [
            {
                "job_id": r["job_id"],
                "summary": r.get("summary", ""),
                "created_at": r.get("created_at", ""),
            }
            for r in ReportArchive(workspace.parent).list_reports()
        ]
        return json.dumps(jobs)

    def get_report(args: dict, workspace: Path) -> str:
        report = ReportArchive(workspace.parent).get_report(args["job_id"])
        if report is None:
            return f"(no report for {args['job_id']})"
        return json.dumps(report)

    return (
        Tool(
            name="graph_query",
            description=(
                "Query the code graph. kind: callers_of(symbol_id), "
                "callees_of(symbol_id), modules_importing(module), "
                "module_imports(module), has_symbol(symbol_id)"
            ),
            handler=graph_query,
        ),
        Tool(name="impact", description="Impact analysis of a symbol (module::name)", handler=impact),
        Tool(name="list_jobs", description="List persisted analysis jobs", handler=list_jobs),
        Tool(name="get_report", description="Get a persisted report by job id", handler=get_report),
    )


class _InstrumentedRegistry:
    """Wraps a ToolRegistry, publishing an ask.tool event per executed tool."""

    def __init__(self, registry: ToolRegistry, bus: EventBus, job_id: str) -> None:
        self._registry = registry
        self._bus = bus
        self._job_id = job_id

    def names(self) -> list[str]:
        return self._registry.names()

    async def execute(self, name: str, args: dict) -> ToolResult:
        result = await self._registry.execute(name, args)
        self._bus.publish(Event(
            type=EVENT_ASK_TOOL, job_id=self._job_id,
            data={
                "tool": name, "args": args, "ok": result.ok,
                "result": result.content[:400], "error": result.error,
            },
        ))
        return result


class AskSession:
    """Persistent chat context for one job; each question runs one Subagent
    turn with prior conversation carried in the task text."""

    def __init__(
        self,
        job_id: str,
        root: Path | str,
        client: LLMClient,
        limits: Limits | None = None,
    ) -> None:
        self.job_id = job_id
        self.root = Path(root)
        self._client = client
        self._limits = limits or get_limits()
        self.history: list[LLMMessage] = []

    def _task_text(self, question: str) -> str:
        if not self.history:
            return f"Question: {question}"
        prior = "\n".join(f"{m.role}: {m.content}" for m in self.history[-6:])
        return f"[Prior conversation]\n{prior}\n\nQuestion: {question}"

    def _registry(self) -> ToolRegistry:
        sandbox = Sandbox(root=self.root, limits=self._limits)
        tools = (*BUILTIN_TOOLS, *_make_chat_tools(self.job_id))
        return ToolRegistry(sandbox, self.job_id, tools=tools, limits=self._limits)

    async def run_turn(self, question: str, bus: EventBus | None = None) -> dict:
        registry = self._registry()
        sub_registry = (
            _InstrumentedRegistry(registry, bus, self.job_id) if bus is not None else registry
        )
        spec = SubagentSpec(
            name="ask", role="chat analyst",
            system_prompt=ASK_SYSTEM_PROMPT, tools=sub_registry.names(),
        )
        subagent = Subagent(
            spec, self._client, sub_registry, bus=bus, job_id=self.job_id,
            model=self._limits.cheap_model,
        )
        report = await subagent.run(self._task_text(question))
        self.history.append(LLMMessage(role="user", content=question))
        self.history.append(LLMMessage(role="assistant", content=report.content))
        if bus is not None:
            bus.publish(Event(
                type=EVENT_ASK_FINAL, job_id=self.job_id,
                data={
                    "answer": report.content, "ok": report.ok,
                    "steps": report.steps, "tool_calls": report.tool_calls,
                },
            ))
        return {
            "answer": report.content, "ok": report.ok,
            "steps": report.steps, "tool_calls": report.tool_calls,
        }
```

```python
    def ask_session(self, job_id: str) -> AskSession:
        with self._lock:
            session = self._ask_sessions.get(job_id)
            if session is None:
                session = AskSession(
                    job_id, self.root, make_client(get_provider(), get_limits())
                )
                self._ask_sessions[job_id] = session
            return session

    def ask_start(self, job_id: str) -> None:
        with self._lock:
            self._ask_queues[job_id] = deque()
            self._ask_done[job_id] = False

    def _publish_ask(self, job_id: str, payload: dict) -> None:
        with self._lock:
            self._ask_queues[job_id].append(payload)

    def ask_snapshot(self, job_id: str) -> tuple[list[dict], bool]:
        with self._lock:
            q = self._ask_queues.get(job_id)
            if q is None:
                return [], self._ask_done.get(job_id, True)
            pending = list(q)
            q.clear()
            return pending, self._ask_done.get(job_id, False)

    def run_ask(self, job_id: str, question: str) -> None:
        session = self.ask_session(job_id)
        bus = EventBus()

        def forward(event: Event) -> None:
            if event.type in (EVENT_ASK_TOOL, EVENT_ASK_FINAL):
                self._publish_ask(job_id, {"type": event.type, "data": event.data})

        bus.subscribe(forward)
        try:
            asyncio.run(session.run_turn(question, bus=bus))
        except Exception as exc:
            self._publish_ask(job_id, {
                "type": EVENT_ASK_FINAL,
                "data": {"answer": f"error: {exc}", "ok": False},
            })
        finally:
            with self._lock:
```

```python
    def _ask(self, job_id: str, question: str) -> None:
        dash = self.server.dashboard
        if not question:
            self._json_error(400, "missing q parameter")
            return
        archive = ReportArchive(dash.root)
        known = job_id in dash._jobs or archive.get_report(job_id) is not None
        if not known:
            self._json_error(404, f"no job {job_id}")
            return
        dash.ask_start(job_id)
        threading.Thread(target=dash.run_ask, args=(job_id, question), daemon=True).start()
        self.send_response(200)
        self.send_header("Content-Type", "text/event-stream")
        self.send_header("Cache-Control", "no-cache")
        self.send_header("Connection", "close")
        self.end_headers()
        while True:
            pending, done = dash.ask_snapshot(job_id)
            for payload in pending:
                line = json.dumps({"type": payload["type"], "data": payload["data"]})
                self.wfile.write(f"data: {line}\n\n".encode("utf-8"))
                self.wfile.flush()
            if done and not pending:
                self.wfile.write(b"event: done\ndata: {}\n\n")
                self.wfile.flush()
                break
            time.sleep(0.1)
```
